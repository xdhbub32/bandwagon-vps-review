## 缺点和限制：这些坑下单前要知道

搬瓦工不是没有短板，有几条直接影响使用体验。

**严格自助管理。** 官网写明 "Strictly self-managed service"，靠这个压低价格。系统配置坏了、环境折腾崩了，官方只管硬件和网络故障，不管你的软件问题。完全没有 Linux 基础的话，上手门槛真实存在。

**客服响应不快。** 上述长期测评作者明确提到客服响应不算快，工单制支持，别指望秒回。

**部分套餐不能换机房。** 常规 KVM 和 CN2 GIA-E 系列支持免费的数据中心间迁移，但 Box 系列、DC Plan 系列、SAKURABOX、新加坡系列都锁死在单一机房。想要“这台机不顺眼就搬走”的灵活性，只能选带迁移的系列——这也是限量版便宜的原因之一。

**25 端口发邮件有变数。** 第三方实测显示 25 端口出站可用，Gmail、Outlook、QQ 邮箱等收发正常，但搜狐邮箱不通。正经做邮件业务的人本来就不该用任何 VPS 直发，这里只提醒随意测试的人。

**热门限量版长期缺货。** 前面已经说过，不再重复。
